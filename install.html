Install Wenxuecity Ad Hider

Choose the Chrome extension to hide ads and block requests to known ad hosts. The Tampermonkey option hides ads on the page.

Chrome extension: hide and block ad downloads

  1. Keep this folder together

    It must contain manifest.json, rules.json, and wenxuecity-no-ads.user.js.

  2. Open Chrome extensions

    Go to chrome://extensions and turn on Developer mode.

  3. Load the folder

    Click Load unpacked and select the folder containing this installation page.

  4. Reload Wenxuecity

    If you also installed the Tampermonkey version, disable that copy to avoid running the same script twice.

Tampermonkey: hide ads on the page

  1. Install Tampermonkey

    Add the official Tampermonkey extension to Chrome.

    Open Chrome Web Store
  2. Allow userscripts in Chrome

    Open chrome://extensions, select Details for Tampermonkey, and turn on Allow User Scripts. If that switch is unavailable, turn on Developer mode on the extensions page. See Tampermonkey’s instructions.

  3. Get the userscript

    Download the script below, open the downloaded file in a text editor, and copy all its contents.

    Download userscript
  4. Save it in Tampermonkey

    Click the Tampermonkey icon, open its dashboard, and choose Create a new script. Replace the editor contents with the copied script and press Ctrl+S (or ⌘+S on Mac).

  5. Reload Wenxuecity

    Visit wenxuecity.com or reload an open article page. Make sure the script is enabled in Tampermonkey.

Keep all four files in this folder. The extension uses manifest.json, rules.json, and wenxuecity-no-ads.user.js; the Tampermonkey download button uses the userscript file.
